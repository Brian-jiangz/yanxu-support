技术支持

使用研序时遇到问题，或有功能建议，可以发邮件至 jiangzheng0332@163.com。

请附上研序版本、iOS 版本和复现步骤。请勿发送 API Key、未公开的科研材料或包含个人信息的备份。

如何备份或迁移记录？

在研序打开「主页 → 设置 → 备份」，导出 JSON 后保存到你选择的位置。恢复会替换备份涵盖的记录，建议先另存一份当前备份。

为什么没有收到提醒？

在 iPhone「设置 → 通知 → 研序」允许通知，再检查对应待办、日程或习惯的提醒时间。

如何停止访问 Zotero？

在研序的设置页清空 Zotero 用户 ID 和 API Key。也可以在 Zotero 的账户设置中撤销该 Key。

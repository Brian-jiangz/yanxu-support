隐私政策

最后更新于 2026 年 11 月 25 日

本机数据

研序无需注册账号。你的个人资料、科研日志、文献笔记、课题、待办、日程、习惯、账目和头像保存在你的设备上。开发者没有接收这些记录的服务器，研序也没有集成广告、追踪或分析 SDK。主 App 和小组件在本机共享部分数据，以显示日程、待办、进度和实时活动。研序可把任务、文献和日志加入设备的系统搜索。

你选择使用的联网功能

按 DOI 补全文献时，研序会将 DOI 发送给 Crossref，获取文献元数据。

预览或刷新课题文献关注时，研序会将检索关键词和日期范围发送给 Crossref。保存关注后，研序会在你打开 App 时定期刷新。研究方向名称、关注配置和检索结果缓存保存在本机的 App 设置中，导出的研序 JSON 不含这些设置。取消关注或删除课题可停止自动检索，已加入文献库的记录会保留。

配置并使用 Zotero 导入时，研序会向 Zotero API 发送你指定的用户 ID 和 API Key，并请求你所选库的元数据和附件。凭据保存在本机钥匙串。清空研序设置里的 Zotero 凭据可停止后续访问，也可在 Zotero 账户设置里撤销该 Key。

添加文献日报的 GitHub Gist 原始链接后，研序会访问这个链接来下载日报。清空设置里的链接可停止后续访问。打开文献里的外部链接时，会连接该链接指向的网站。

外部服务会按各自的条款和隐私政策处理请求，可能记录 IP 地址等连接信息。研序只在使用相应功能时进行这些连接。

系统通知与照片

系统通知经你授权后用于待办、日程、习惯和晨报提醒，可在系统设置中关闭。研序通过系统照片选择器获取你主动选中的头像。

备份、保留和删除

研序保留最近约七天的本机自动备份。在设置中导出 JSON 时，备份会包含个人资料及可备份的科研和生活记录。分享或存档位置由你选择。

你可以在相应页面删除记录。若要移除设备上的研序资料，可先清空 Zotero 凭据，再卸载 App 及其小组件。你自行导出或分享的文件和外部服务持有的数据，需要在对应位置或服务中单独管理。设备备份由你的系统设置管理。
